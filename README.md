# 🏠 Homie 3D - Furniture Selection Helper

ยินดีต้อนรับสู่ **Homie 3D** แพลตฟอร์มช่วยตัดสินใจเลือกซื้อเฟอร์นิเจอร์ผ่านระบบ **3D Visualization และ Augmented Reality (AR)** ที่จะทำให้คุณเห็นภาพเฟอร์นิเจอร์จริงในบ้านของคุณก่อนการตัดสินใจซื้อ

## 🌐 Live Website
เข้าชมเว็บไซต์ได้ที่: [**https://miyomui.github.io/furniture-3d/**](https://miyomui.github.io/furniture-3d/)

## ✨ คุณสมบัติเด่น (Features)
- **3D Interaction:** หมุน ซูม และดูรายละเอียดเฟอร์นิเจอร์ได้แบบ 360 องศา
- **Augmented Reality (AR):** นำเฟอร์นิเจอร์ไปวางในพื้นที่จริงผ่านกล้องมือถือ (รองรับทั้ง iOS และ Android)
- **Furniture Categories:** แยกหมวดหมู่ชัดเจน (Living Room, Bedroom, Dining Room, Office, Outdoor)
- **Optimized Performance:** ใช้ระบบ Lazy Loading และ Draco Compression เพื่อการโหลดที่รวดเร็ว

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend:** HTML5, CSS3 (Vanilla CSS), JavaScript
- **3D Rendering:** [Google <model-viewer>](https://modelviewer.dev/)
- **Deployment:** GitHub Pages & GitHub Actions
- **3D Optimization:** Git LFS & gltf-pipeline (Draco Compression)

## 📂 โครงสร้างโฟลเดอร์
- `index.html`: ไฟล์หลักของเว็บไซต์
- `style.css`: ไฟล์สไตล์ลิ่งระดับ Premium
- `3D/`: โฟลเดอร์เก็บไฟล์โมเดล `.glb` และ `.usdz`
- `images/`: ไฟล์รูปภาพประกอบและ Header
